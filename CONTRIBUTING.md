# Contributing

Contributions are welcome! Useful areas include device and card compatibility, read-only protocol discovery, sync performance and reliability, accessibility, and privacy-preserving integrations.

1. Open or comment on a GitHub issue before starting substantial changes.
2. Fork the repository and create a focused branch from main.
3. Follow the build and test instructions in README.md. Add tests for behavioral changes.
4. Open a pull request describing the change, test results, and any device or OS compatibility limitations.

Only submit code and assets you have the right to contribute. By submitting a contribution for inclusion, you agree to license it under the project's MIT License. Third-party dependencies must have compatible licenses and attribution.

Never submit real CPAP therapy data, patient identifiers, credentials, tokens, signing assets, or unsanitized logs/screenshots. Use synthetic fixtures. Preserve read-only access to the CPAP card and do not change therapy settings or interfere with device operation. Do not test on a device during active therapy.

Report ordinary bugs in Issues. For sensitive security or privacy issues, use GitHub private vulnerability reporting if available; otherwise contact the maintainer privately. Never publish sensitive details in an issue.

Maintainers review and decide which changes are accepted; contributions do not grant write access or release permissions.
